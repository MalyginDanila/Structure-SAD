|   |   ├── Что входит в объём решения
|   |   └── Что не входит в объём решения
|   |

│   └── Ключевые архитектурные решения

│   │

│   │
│   └── Нефункциональные требования
│       ├── Масштабируемость
|       ├── Достуность и надёжность
|       ├── Производительность

│       └── Безопасность
│
├── 3. Концептуальный обзор решения
│   │
│   └── Концептуальная и логическая архитектура

│   ├── Информационная архитектура

|   |   └── Компоненты приложения
|   ├── Архитектура данных
|   |   └── Поток данных и контекст
|   ├── Архитектура интеграции
|   |   └── Интерфейсный компонент
│   ├── Архитектура инфраструктуры
|   |   └── Компоненты инфраструктуры
│   └── Архитектура безопасности

|       └── Модель угроз для приложения

│   │
│   ├── Разработка

│   │
│   ├── Управление эксплуатацией
|   |   ├── Мониторинг и оовещения
|   |   ├── Поддержка и управление инцидентами
|   |   └── Аварийное восстановление
|   |
│   └── Онбординг пользователей
|       └── Пользовательские требования к системе

└── 7. Приложение
    │
    ├── Окружения и стенды
